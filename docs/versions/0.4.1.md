Fluye 0.4.1 mejora la activación del dictado y la escritura en paneles integrados, como el chat de Claude dentro de Excel.

- Activación más rápida: el control de escritura se prepara al iniciar Fluye y el micrófono puede abrirse mientras se identifica el destino.
- Nuevo indicador «Preparando el micrófono» antes de empezar a escuchar.
- Se conserva el campo de texto original, además de la ventana. Al volver desde otra aplicación se recuperan el panel y el editor antes de pegar.
- Se evita reactivar innecesariamente una ventana que ya tiene el foco, lo que podía desviar el dictado a una celda de Excel.
- Si no se puede recuperar el destino, el texto queda en el portapapeles y se muestra un aviso específico.
- Se mantiene la restauración del portapapeles tras el pegado y se evita que el aviso de un dictado anterior interrumpa el siguiente.

Validado manualmente con Claude dentro de Excel, cambio a Bloc de notas durante el dictado, restauración del portapapeles y pulsaciones cortas. Incluye 14 comprobaciones automáticas del proceso de escritura y de la recuperación del foco, con proveedores de Windows simulados para estas últimas.

Descarga **Fluye-Setup-0.4.1.exe** para Windows x64 o busca actualizaciones desde la aplicación instalada. La transcripción local sigue incluida y no necesita clave API. El instalador no está firmado digitalmente.
